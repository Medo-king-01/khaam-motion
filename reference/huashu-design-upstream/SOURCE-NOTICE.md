# Huashu Design source subset — provenance and boundaries

**Upstream:** [alchaincyf/huashu-design](https://github.com/alchaincyf/huashu-design), reviewed at commit `59065698ad63f87ea1532c126c87f488d4f93fd6` (master, 2026-11-27). Upstream declares MIT; its original `LICENSE` is retained here.

This curated, unchanged source subset contains Huashu's full design-style reference, animation best-practices, camera-language, direction and critique guides; the seven original style overview sheets; and nine source-only examples with their original screenshots, selected for explanatory graphics, information design, diagrammatic slides and motion metaphors. `UPSTREAM-MANIFEST.sha256` covers every copied upstream file except this notice and the manifest.

This is **not** a second Khaam skill or renderer. The upstream `SKILL.md`, scripts, runtime/vendor libraries, sound effects, music, fonts, bird-sticker kit, generic app/web/PPT production pipelines and remaining style sample source are not copied. The sticker kit has its own PolyForm Shield license and is intentionally excluded. The retained HTML examples are for source inspection, not drop-in deliverables: several link Google Fonts remotely and use Chinese copy/type. Do not launch them as production projects, use their external fonts/assets without the normal Khaam license/permission checks, or infer Arabic suitability from their screenshots.

`reference/huashu-design.md` is the Khaam-specific adapter and decision boundary. It preserves Khaam's existing approval gates, HyperFrames/Remotion setup, pace, Arabic, asset permissions, real-sound policy and delivery checks; it does not import Huashu's mandatory three-direction rule, default music, watermark or fixed export settings.
