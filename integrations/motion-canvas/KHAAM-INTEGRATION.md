## What it is
Motion Canvas: a TypeScript library for creating animated videos using the Canvas API and a generator-based programming model.

## Key capabilities
- Generator-based animation model (`yield*`) for precise timing
- 2D vector/canvas scene primitives and code-driven animations
- Editor/player/docs/examples/packages for programmatic video workflows

## How to use in Khaam
Use as an alternative/supplemental programmatic animation engine reference. Khaam default remains HyperFrames/Remotion as appropriate; evaluate Motion Canvas when generator-based 2D canvas workflow fits. Install deps in a separate project; keep Arabic text shaping/RTL rules when adapting.
