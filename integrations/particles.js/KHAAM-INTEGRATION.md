## What it is
A lightweight JavaScript library for creating particle effects (canvas-based), commonly used for interactive backgrounds and visual flourishes.

## Key capabilities
- Simple particle system configuration (JSON-driven).
- Canvas particle rendering: movement, density, color, shape, interactivity.
- Good reference for lightweight particle backgrounds/effects.

## How to use in Khaam
- Use as reference for particle visual ideas or in web prototypes.
- For deterministic video rendering, adapt particle state to frame/time-based updates; avoid relying on interactive mouse events in final render.
- For more modern/maintained particle features, also consider tsParticles integration.
