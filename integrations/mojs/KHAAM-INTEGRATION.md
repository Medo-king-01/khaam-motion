## What it is
mo.js motion graphics toolbelt for the web (shapes, bursts, tweens, timelines, motion paths).

## Key capabilities
- Web motion primitives (shape, burst, stagger, timeline, path easing)
- Small source reference for procedural web animations
- Useful patterns for micro-interactions and UI motion

## How to use in Khaam
Use as reference/source for web animation patterns or in web-based motion prototypes. For Khaam video rendering, prefer deterministic frame-driven animation; do not rely on wall-clock DOM animation in rendered pipelines without verification.
