## What it is
Over 6500 free MIT-licensed high-quality SVG icons (outline + filled styles).

## Key capabilities
- Large icon coverage across many categories
- Outline and filled variants for visual hierarchy
- Useful fallback when Lucide/simple-icons lack a needed symbol

## How to use in Khaam
Use when a concept/brand-generic symbol is missing from Lucide, or when filled/outline variants help hierarchy. Keep style consistent; avoid mixing many icon families in the same frame unless intentional.

## Notes
- Preserve upstream LICENSE and provenance.
- Prefer Lucide for default UI consistency; use Tabler as the broad fallback/extension set.
- Apply Khaam rules for Arabic typography, sound discipline, pace, and QA.
