## What it is
GSAP (GreenSock Animation Platform) is a high-performance JavaScript animation library for web/CSS/SVG/canvas/WebGL/JS objects, with plugins like ScrollTrigger, MotionPath, etc. (plugin availability/licensing may vary by GSAP terms).

## Key capabilities
- High-performance tween/timeline animation engine.
- Animates DOM/CSS/SVG/canvas/generic objects.
- Rich easing, sequencing, staggering, motion paths, scroll-driven patterns (plugin-dependent).
- Useful reference for motion timing/easing vocabulary and web animation implementation.

## How to use in Khaam
- Use as reference or in web-based prototypes/Remotion/web-render pipelines where GSAP fits.
- For rendered video, ensure animations are frame-driven/deterministic (not wall-clock dependent) and verify render capture.
- Check GSAP Standard License terms before any redistribution/commercial/productized use.
